# Code review checklist

- [ ] Core ei sõltu WPF-projektist.
- [ ] WPF kutsub Core-meetodeid ega sisalda domeenireegleid.
- [ ] Pärilus ja override on korrektsed.
- [ ] Liidese kontroll kasutab `is` kontrolli.
- [ ] Vigane sisend ei muuda objekti olekut.
- [ ] Piirjuhtumid on kontrollitud.
- [ ] Projekt kompileerub.
- [ ] PR on Issue-ga seotud.
